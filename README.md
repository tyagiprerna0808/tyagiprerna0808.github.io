# Prerna Tyagi GitHub Pages Site

This repository is the publish-ready GitHub Pages site for Prerna Tyagi.

## Files

- `index.html`: landing page and structured data
- `robots.txt`: crawler directives
- `sitemap.xml`: sitemap for indexing
- `.nojekyll`: ensures GitHub Pages serves the files directly

## Publish

1. Create a GitHub repository named `tyagiprerna0808.github.io`.
2. Upload these files to the repository root.
3. Enable GitHub Pages if needed.
4. Confirm `https://tyagiprerna0808.github.io/` loads successfully.
