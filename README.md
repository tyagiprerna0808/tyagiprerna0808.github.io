# Prerna Tyagi GitHub Pages Site

This repository is the publish-ready GitHub Pages site for Prerna Tyagi.

## Files

- `index.html`: landing page and structured data
- `robots.txt`: crawler directives
- `sitemap.xml`: sitemap for indexing
- `.nojekyll`: ensures GitHub Pages serves the files directly

## Publish

1. Create a GitHub repository named `tyagiprerna0808.github.io`.
2. Upload these files to the repository root.
3. Enable GitHub Pages if needed.
4. Confirm `https://tyagiprerna0808.github.io/` loads successfully.

## If you dislike the GitHub URL

Use a custom domain so your site looks professional.

1. Buy a domain from Namecheap, GoDaddy, Cloudflare, or Google Domains alternatives.
2. Good examples: `prernatyagi.com`, `prernatyagi.ai`, `prernatyagi.dev`.
3. In your GitHub repo settings, open Pages and set the Custom domain.
4. Add a file named `CNAME` in repo root containing only your domain, for example: `prernatyagi.com`.
5. In your domain DNS, add these records:
	- `A` record: `185.199.108.153`
	- `A` record: `185.199.109.153`
	- `A` record: `185.199.110.153`
	- `A` record: `185.199.111.153`
6. Wait 10 minutes to 24 hours for DNS propagation.
7. Update `canonical`, `og:url`, `sitemap.xml`, and `robots.txt` to your new domain.
